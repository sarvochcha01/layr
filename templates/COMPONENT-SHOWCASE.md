# Component Showcase Template

A comprehensive template that demonstrates all available components in the design system, organized by category for easy exploration and reference.

## Overview

This template provides a complete showcase of every component available in the system, with each category getting its own dedicated page. It's perfect for:

- Learning what components are available
- Seeing real-world examples of each component
- Understanding component variations and configurations
- Testing components in different contexts
- Building a component library reference

## Pages

### 1. Home (`/`)
Landing page with overview of all component categories and navigation to each section.

**Components Featured:**
- Hero section with call-to-action
- Grid layout with category cards
- CTA section
- Footer

### 2. Layout (`/layout`)
Structural components for organizing page layouts.

**Components Featured:**
- Header
- Navbar
- Section
- Container
- Grid
- Footer

### 3. Content (`/content`)
Core content components for building engaging pages.

**Components Featured:**
- Hero (multiple sizes and alignments)
- Card (with images and links)
- Text (various sizes and styles)
- Button (all variants and sizes)

### 4. Media (`/media`)
Image and video components with responsive layouts.

**Components Featured:**
- Image (various aspect ratios)
- Video (embedded and responsive)

### 5. Forms (`/forms`)
Form components for user input and data collection.

**Components Featured:**
- Form (contact form example)
- Form (signup form example)
- Various input types (text, email, tel, select, textarea, checkbox)

### 6. Interactive (`/interactive`)
Dynamic components for engaging user experiences.

**Components Featured:**
- Accordion (FAQ example)
- Tabs (content switcher)

### 7. Marketing (`/marketing`)
Components designed to convert and engage visitors.

**Components Featured:**
- Testimonial (customer reviews)
- PricingCard (pricing tiers)
- Feature (feature highlights)
- Stats (key metrics)
- CTA (call-to-action sections)

### 8. UI Elements (`/ui-elements`)
Small but essential UI components for polish and functionality.

**Components Featured:**
- Divider (various styles)
- Spacer (vertical spacing)
- Badge (all variants and sizes)
- Alert (all types: success, info, warning, error)

## Usage

1. Import this template in your editor
2. Navigate through each page to see components in action
3. Inspect component properties to understand configuration options
4. Copy and modify components for your own projects

## Design Tokens

All components use the design system's CSS custom properties for:
- Colors (background, foreground, primary, muted, etc.)
- Borders
- Spacing
- Typography

This ensures consistent theming and automatic light/dark mode support.

## Customization

Each component can be customized through its props:
- Colors and backgrounds
- Spacing and sizing
- Typography
- Layout and alignment
- Content and data

Refer to individual component documentation for detailed prop specifications.
